# Network Traffic Analyzer — Screenshots

This directory contains real screenshots captured during the testing of the Network Traffic Analyzer project.

## 1. Network Interface Discovery

**File:** `interfaces.png`

Displays the network interfaces detected by the tool on a Windows system using Npcap. This demonstrates the interface discovery feature, which helps users identify an interface for packet capture.

## 2. ICMP Packet Capture

**File:** `icmp-capture.png`

Shows actual ICMP packet metadata captured on the loopback interface during testing. The output demonstrates how the analyzer displays packet timestamps, protocol, source and destination IP addresses, and packet size.

## What These Screenshots Demonstrate

- Network interface discovery
- Live ICMP packet capture
- Structured packet metadata output
- Practical testing of core project functionality

## Testing Notes

- Screenshots were captured from the project running in a local Windows environment.
- Network interface names and IP addresses may differ across systems.
- Packet capture may require administrator privileges and a compatible Npcap installation on Windows.
- The project should only be used on networks and systems you own or are authorized to monitor.

Additional screenshots may be added to demonstrate TCP and UDP packet capture, protocol filtering, and configurable packet limits.
